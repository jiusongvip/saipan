# E2E 验收（待浏览器运行器批准后落地）

开发文档 8.2 的人工验收项在自动化层的落点。当前仓库未引入浏览器运行器
（Playwright 等属依赖决策，见 docs/handoff/STATUS.md 阻塞项），本目录先登记
验收脚本的规划，不放置空壳测试。

规划（每项对应文档 8.2）：

1. 桌面端与移动端首页、方案页、费用页、医生页、入境页、表单流程的截图比对。
2. 五种语言切换与页面回退逻辑（缺译文回退到该语言真实存在的首页）。
3. 表单成功、API 失败、网络失败、重复提交四条路径。
4. CTA 事件在测试环境触发正确、参数不含个人信息
   （静态断言见 tests/integration/form-pipeline.test.ts，本目录补运行时验证）。
5. 旧站主要 URL 与图片路径重定向检查（待旧域 URL 导出后可用）。

落地条件：项目负责人批准浏览器运行器依赖 + staging URL 可用。
